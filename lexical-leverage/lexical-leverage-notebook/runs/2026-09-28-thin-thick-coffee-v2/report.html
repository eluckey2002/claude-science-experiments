Does "Make it modern" still matter once the brief has a style guide?

No. With a one-line brief the word reshaped the page every time. Put a short style guide in front of the same brief and the word did nothing measurable.

Behind the style guide: every one of these stayed exactly where the guide put it, in every run, with or without the word.

The surprise. We expected a vague word to make pages less consistent, since everyone's "modern" is different. The opposite happened. Without the word Sonnet chose three different fonts in five runs; with it, one font five times. For Sonnet, "modern" is not vague. It is a recipe: system font, frosted blur, bigger corners, more gradients. The next word to test should be one the model has no recipe for.

5. What was actually sent

Brief (all 30 pages):

Build a single-file landing page (HTML with embedded CSS, no external libraries) for a neighbourhood coffee shop called Northside Roast. Include a header, a hero, a short menu section, opening hours, and a footer. Return only the HTML.

Style guide (thick pages only, placed before the brief):

Design spec (follow exactly):
- Body font: Lora (serif). Heading font: Playfair Display (serif). Load both via Google Fonts links.
- Page background: #FAF6F0 (light cream). Body text colour: #2B1D14.
- Accent colour (buttons, links, highlights): #7A4A2A (espresso). No other accent hues.
- Border radius: 4px on all rounded elements. No pill shapes.
- No gradients. No CSS animations or transitions. No box shadows.
- Content max-width: 1100px, centred.
- Header is static (not sticky, not fixed).

Wordings, inserted before "Return only the HTML.": nothing · "Write all copy in English." · "Make it modern."

Before spending on the batch: one page per cell was generated first to confirm the one-line brief did not already produce a system font, that the style guide was actually followed, and to set the output cap from the longest page. All three checks passed.

6. Limits

One word, one brief, one model, five runs per condition. The answers are majority votes, not effect sizes. The style guide pinned exactly the properties we measure, which is the strongest version of the test; a guide that pins some things and leaves others open is the natural next version, as is a word without a built-in recipe ("professional", "clean").
